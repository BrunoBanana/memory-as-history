# Benchmark results — 2026-09-18

Memory as History satisfies the 990 checks in the authored history protocol
corpus. Its ordinary external evidence retrieval matches reference BM25 at
**42.76% mean Recall@5**. These results establish a reproducible baseline and
identify multi-evidence retrieval as a substantial gap. They do not demonstrate
better retrieval than BM25, official LoCoMo QA performance or industry leadership.

## Track B: external retrieval under equal content budgets

The run indexes 5,882 turns across ten conversations and accounts for all 1,986
questions. Exactly 1,527 are scored. The remaining 459 are explicitly excluded:
446 category-5 adversarial questions, 4 with no evidence and 9 with unresolved
evidence IDs. No excluded question receives abstention credit. This is 76.89%
coverage of all questions, or 99.16% of the 1,540 non-adversarial questions.

Each system may return at most **5 whole turns / 4,096 UTF-8 content bytes**.
The same speaker/text/caption inputs, tokenization, tie-breaking and budget
selector are used. Product ranking is the real reopened SQLite recall path;
reference BM25 independently implements the equation with the shared tokenizer.
There are no privileged anchor/canon/narrative labels in this track.

| System | Mean evidence Recall@5 | Any evidence Hit@5 | MRR@5 |
| --- | ---: | ---: | ---: |
| Memory as History | 42.7586% | 47.6097% | 0.333694 |
| Reference BM25 | 42.7586% | 47.6097% | 0.333694 |
| Recency | 0.1801% | 0.2620% | 0.001146 |

Product/reference recall comparisons are 0 wins / 1,527 ties / 0 losses.
Product/recency comparisons are 727 wins / 796 ties / 4 losses. Recency is a
limited baseline for questions about entire histories; it represents no competing

## What failed, and what to improve

The following analysis uses the published IDs and scores without changing labels
or tuning the production ranker on this dataset:

| Evidence required | Questions | Mean recall | Questions retrieving all gold |
| --- | ---: | ---: | ---: |
| One turn | 1,122 | 52.05% | 584 |
| Multiple turns | 405 | 17.02% | 13 |

Only 21 questions require more than five gold turns; none has total gold content
exceeding 4,096 bytes. A perfect selector under these same budgets has a mean
recall ceiling of 99.50%. Thus the budget explains little of the observed gap;
ranking and evidence coverage deserve investigation. This ceiling uses gold
after scoring and is not another system's result.

Twenty question/evidence pairs have no shared query token under the current
tokenizer. This is a lexical diagnostic, not a count of all semantic/paraphrase
failures: shared tokens alone do not establish relevance. The adapter also omits
session-date metadata equally for all systems, so temporal retrieval and time
reasoning need a separate, explicitly controlled experiment.

Next retrieval milestone:

1. Freeze a development workload for paraphrase, entity references, dated changes
   and multi-evidence questions. Treat this already-inspected LoCoMo run as a
   public regression/reference set, not a future blind test.
2. Compare semantic and hybrid retrieval, bounded neighboring-turn expansion and
   date-aware retrieval against this lexical baseline. Keep evidence labels out
   of preprocessing/ranking and retain equal context budgets and coverage counts.
3. Select configurations only on development data, then evaluate on independently
   prepared unseen histories. Require improved multi-evidence coverage without
   regressing stale-source suppression, provenance gates or protocol contracts.
4. Add a separate reader/agent experiment for answer correctness, correct
   abstention and unguided tool selection; record model/version, token costs and
   repeated trials. Retrieval scores alone cannot establish these behaviors.

## Operational observations and validation

On the recorded local run, product query latency was p50 4.66 ms / p95 5.15 ms;
reference BM25 was 0.56 / 0.79 ms; recency was 0.0025 / 0.0036 ms. Product timings
include SQLite access; references are in-memory rankers. These are descriptive
single-machine measurements, not throughput, cold-start or stress guarantees.
The ten SQLite files totaled 3,297,280 bytes for 5,882 turns; this is a final
snapshot, not a storage-growth measurement. Full indexing timings are retained.

Local validation covers 267 tests under MCP 1.2.0, 1.30.0 and 2.2.0, plus the
installed-wheel checks recorded in the implementation plan. The public protocol
track runs in the existing six OS/Python CI jobs; three MCP compatibility jobs
remain separate. CI does not fetch external data or require a model credential.
Exact PR/main check status is the integration authority, not this dated report.

The project now has a falsifiable public baseline. Independent reproduction,
genuinely unseen histories, semantic/temporal baselines, online updates,
backup/crash recovery at larger scales and unguided agent trials remain open.
