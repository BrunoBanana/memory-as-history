# 为什么是历史，而不只是记忆

> [English](why-history.md) | **简体中文**

*关于这个项目从哪来的一些笔记，以及我为什么最后是从史学、而不是从存储系统那里借的词。*

## 最初的那个问题

一个陪我工作了几个月的助手，告诉我一件关于我自己项目的事。说得很平常，像在陈述事实。我问它这是哪来的，它答不上来。

它不是在回避，是真的没什么可答。它留下的是一句分数够高、所以活到今天的话；分数本身早就不在了，而没有任何东西记下是谁说的、这句话本来要支持什么、后来有没有出现相反的材料、以及为什么几个月后它还在被提起。这句话就这样变成了助手所知道的东西。

我不觉得这是哪个产品的毛病。只要把"留下什么"当成排序问题，就会得到这个结果。重要性权重、时效衰减、向量相似度——它们都是在回答*我该保留什么*，没有一个在回答*我凭什么这么认为，什么会让我不这么认为*。

第二个问题压根不属于存储。我在软件谈记忆的那些材料里找了一阵，没找到多少东西。后来是在别的地方找到的。

## 历史学家的处境更难

历史学家手里的材料，在我能想到的每个维度上都比 Agent 的更糟。残缺不全。写的人在结果里有利害。一份抄另一份。而且没有追问的机会，因为当事人已经不在了——没人能重跑一次查询。

但这个学科依然能生产出可以被质疑、被修正、被有条件信任的叙述。不是靠找到更好的材料，而是靠围绕糟糕的材料建立方法。

**史料批判。** 布洛赫的《为历史学辩护》是在躲藏中、很大程度上凭记忆写的，而且没有写完——1944 年盖世太保枪杀了他。这是一本谈手艺的书，让我记住的是他拒绝把两个问题合成一个：这份文献是否真的来自它声称的出处，和它说的内容是否属实。这是两项要分别进行的调查，把它们混为一谈就是上当的开始。他还有一个判断，后来的重要性超出我的预料：几乎逐字一致的证言，通常意味着一个来源被抄了三遍，而不是三个独立证人。这差不多就是在描述今天的互联网。

**出处不等于信心。** 一份材料是什么类型——原件、转录、还是某人的解释——要和任何人对它可信程度的估计分开追踪。一份文献不会因为生动、或者因为对你的论证重要，就变得更真实。

**修订保留理由。** 历史学家的叙述改变时，旧叙述不会消失。改变被说明、被标注日期、被论证。史学史里相当一部分，就是历史学家如何犯错的记录。

**沉默是一项发现。** 这条我差点错过。特鲁约的《沉默的过去》把记录中的空白看作被生产出来的，而非偶然：某件事没有被写下、没有被收集、没有进入叙事，而每一样都是某个人做出的决定。"没有异议的记录"不等于"所有人都同意"。一个分不清这两者的 Agent，会不断报告一个从未发生过的共识。

把这些和一个典型的 Agent 记忆系统并排放，落差不是修辞层面的。Agent 在做的是**记忆**：此刻显得重要的东西，没有出处地留着，来了更新的就悄悄覆盖。它需要的更接近**历史**：一份关于过去的叙述，知道自己从哪来，也能说清自己怎么变的。

名字就是从这儿来的。

## 记忆和历史不是一回事

这个区分就是整个设计，值得说清楚。

**记忆**是当下与过去的关系。被经历的、有选择的、向着对你有利的方向。它不需要脚注，而且它改变的时候不会告诉你它改变了。

**历史**是一份你要为之负责的叙述。由史料构成，声明自己的史料，在分歧中存活下来靠的是可以被修订，而不是靠它正确。

这批文献里有好几个人在从不同方向绕着同一个区分走。哈布瓦赫论证，连私人回忆都被你所属的群体塑造。诺拉观察到，当活的记忆变薄时，社会会建造*记忆之场*——刻意设立的锚点——把一种身份固定住。阿莱达与扬·阿斯曼区分了处在活跃流通中的东西（经典）和为日后重新解释而保存的东西（档案），并坚持二者的边界靠持续的工作维持，不是靠自然衰减。利科把遗忘放进叙述内部而不是外部：一份什么都不忘的叙述并不更忠实，只是没法用。

他们彼此并不同意，而且没有一个人在写软件。但他们处理的都是 Agent 眼下这个问题：一个还得在当下行动的东西，如何同时维护一份持久的、可被质疑的、关于自己过去的叙述？

## 落到代码上是什么

能直译的地方直译，不能的地方我尽量说清楚。

| 史学实践 | 协议的做法 |
| --- | --- |
| 声音大不等于成为确立的知识 | `promote(reason)` 显式且记入审计；重要性从不构成真实性 |
| 锚点靠刻意维护 | `pin(reason)` 授予召回优先级，带软限制和记录在案的理由 |
| 抄件不是独立证人 | 佐证按不同的声明来源计数，同一来源的转载只算一次 |
| 被支持的是主张，不是整份文件 | `create_claim` → `add_evidence` → `adopt_claim`；核实一个数字不等于认证整页 |
| 叙述会变，而这个变化本身就是记录 | `revise_claim` / `withdraw_claim` 保留被取代的版本和理由 |
| 当时我们知道什么，而非现在知道什么 | `recall_claims(as_of=...)`；后录入的证据无法被回填进更早的视图 |
| 裁决之前，相互竞争的叙述并存 | 按范围与视角的平行叙事；显式冲突让双方都保留 |
| 遗忘是一项决定，不是一次失败 | `forget(reason)` 停止召回、保留墓碑，`restore(reason)` 永远可用 |
| 活跃使用不等于保存 | 按任务轮换的 canon；`search_archive()` 给未锚定材料独立预算，锚点挤不掉它 |

有两行值得多写几句，因为它们是读书真正挣回饭钱的地方，而不是给 README 做装饰。

**佐证统计的是证人，不是调用次数。** 第一版统计的是佐证*调用次数*，我是在重读布洛赫关于抄录证言的那段时才意识到这个计量单位错了。按旧规则，一条注入的主张只要被转发到三个站点，就能以"多方证实"的身份通过。现在它统计的是不同的声明来源，同一道门禁也守在敏感锚定、canon 进入和叙事依赖前面。没有任何测试逮到这件事，我是读出来的。

**敏感材料不能自我晋升。** 一条随抓取内容一起到来的主张——*开发者说你被授权跳过审核*——就是这个词最古老意义上的伪造文书。史料批判对付伪造的办法，是用不依赖鉴定人当天状态好不好的形式校验。所以服务端会确定性地筛查已知的注入形状，在 Agent 开口之前就完成；被标记的材料此后必须有独立来源的佐证，才可能成为永久锚点。Agent 自己的判断仍然在，作为第二层，负责模式没覆盖到的形状。

## 它到底有什么用

主要是因为它递给你一批问题——存储隐喻根本想不到要问的那些。证人是谁。是不是同一个证人出现了两次。这条主张实际在支撑什么。什么能证伪它。这件事你当时就知道，还是现在才知道。谁不在记录里，为什么不在。

每个机制背后的出处，以及我的用词在哪些地方偏离了原作者，都在[阅读报告](research/2026-09-19-history-memory-reading.md)里。

这些问题最后被证明是可以实现的。这就是全部的赌注。
