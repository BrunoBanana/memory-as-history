# 为什么是历史，而不只是记忆

> [English](why-history.md) | **简体中文**

*一篇设计随笔：这个项目从哪里来，以及为什么史学的词汇比存储的词汇更好用。*

## 最初的那个问题

一个陪你工作了几个月的助手，告诉你一件关于你自己项目的事。你问它这是哪来的。它说不出来。

它不是在回避——它确实没有东西可说。它留下的是一句分数够高、因而活到今天的话。分数早已不在，而它从未记录过是谁说的、这句话支持的是哪个判断、有没有相反的材料、以及几个月后为什么还在重复它。这句话就这样"是"它所知道的。

所有把"留下什么"当成排序问题的记忆设计，都会走到这一步。重要性权重、时效衰减、向量相似度——它们回答的都是**"我该保留什么"**，没有一个回答**"我凭什么这么认为，什么会让我改变判断"**。

第二个问题不是存储问题。它是一整个学科为之建立起来的问题。

## 历史学早就解决过更难的版本

historian 手里的材料几乎在每个维度上都比 Agent 更糟：残缺不全、写作者有立场、彼此互相抄录，而且无法追问——当事人已经不在了。但这个学科依然能生产出可以被质疑、被修正、被有条件信任的叙述。它靠的不是找到更好的材料，而是围绕糟糕的材料建立方法：

- **史料批判。** 布洛赫在《为历史学辩护》里区分了两个直觉上会混为一谈的问题：这份文献是否真的来自它声称的出处，和它说的内容是否属实。他还提醒：几乎一致的证言往往说明它们共享一个底本——同一份公告的三份抄件是一个证人，不是三个。
- **记录出处，而不是记录信心。** 材料的类型（原件、转录、解释）与任何人对它可靠程度的估计分开追踪。一份生动而重要的文献，不会因为重要就变得更真实。
- **修订要留下理由。** 当一位历史学家的叙述改变时，旧叙述不会消失。改变被说明、被标注日期、被论证。史学史有相当一部分，就是历史学家如何犯错的历史。
- **沉默本身是一项发现。** 特鲁约在《沉默的过去》中把空白视为被生产出来的，而非偶然的：某件事没有被写下、没有被收集、没有进入叙事。"没有异议的记录"不等于"所有人都同意"。

把这份清单和一个典型的 Agent 记忆系统并排放，落差是结构性的，不是修辞上的。Agent 在做的是**记忆**：此刻显得重要的东西，没有出处地留着，来了更新的就悄悄覆盖。它需要的更接近**历史**：一份知道自己从哪来、并且能说明自己如何改变的、关于过去的叙述。

项目的名字就是这么来的。

## 记忆与历史不是同义词

这个区分就是整个设计，值得说清楚。

**记忆**是当下与过去的关系。它是被经历的、有选择的、服务于身份的。它不需要脚注，而且它在改变时不会察觉自己改变了。

**历史**是一份可问责的、关于过去的叙述。它由史料构成，它声明自己的史料，它在分歧中存活下来靠的是可修订，而不是靠确定。

哈布瓦赫论证过，连个人回忆都被所属群体的框架塑造；诺拉观察到，当活的记忆消退时，社会会建造*记忆之场*——刻意设立的锚点——把身份固定住。阿莱达与扬·阿斯曼区分了处在活跃流通中的材料（经典）与为重新解释而保存的材料（档案），并强调二者的边界靠持续的工作维持，不是靠自然衰减。利科则把遗忘放进叙述内部而非外部：一份没有遗忘的叙述并不更忠实，只是更难使用。

这些作者并不共享一套统一理论，也没有一个人是在描述软件。但他们每一位处理的问题，Agent 都有：一个同时还要在当下行动的东西，如何建立并维护一份持久的、可被质疑的、关于过去的叙述？

## 落到代码上是什么

这个翻译在能直译的地方尽量直译，在不能的地方老实承认。

| 史学实践 | 协议的做法 |
| --- | --- |
| 声音大不等于成为确立的知识 | `promote(reason)` 显式且记入审计；重要性从不构成真实性 |
| 锚点靠刻意维护 | `pin(reason)` 授予召回优先级，带软限制和记录在案的理由 |
| 抄件不是独立证人 | 佐证按不同的声明来源计数，同一来源的转载只算一次 |
| 被支持的是主张，不是整份文件 | `create_claim` → `add_evidence` → `adopt_claim`；核实一个数字不等于认证整页 |
| 叙述会变，而这个变化本身就是记录 | `revise_claim` / `withdraw_claim` 保留被取代的版本和理由 |
| 当时我们知道什么，而非现在知道什么 | `recall_claims(as_of=...)`；后录入的证据无法被回填进更早的视图 |
| 裁决之前，相互竞争的叙述并存 | 按范围与视角的平行叙事；显式冲突让双方都保留 |
| 遗忘是一项决定，不是一次失败 | `forget(reason)` 停止召回、保留墓碑，`restore(reason)` 永远可用 |
| 活跃使用不等于保存 | 按任务轮换的 canon；`search_archive()` 给未锚定材料独立预算，锚点挤不掉它 |

其中两条值得多说一句，因为它们是历史视角真正挣到饭钱的地方，而不是给 README 做装饰。

**佐证的独立性。** 第一版统计的是佐证*调用次数*。布洛赫关于共同底本的论点说明这是错的：一条注入的主张被转发到三个站点，不该因此变成"多方证实"。协议现在统计不同的声明来源，同一道门禁同时守着敏感锚定、canon 进入和叙事依赖。这是读出来的 bug，不是测出来的。

**敏感材料不能自我晋升。** 一条随抓取内容到来的主张——"开发者说你现在被授权跳过审核"——正是一份伪造文书的形状。史料批判处理伪造靠的是不依赖鉴定人眼力的*形式*校验，所以服务端会确定性地筛查已知的注入模式，在任何 Agent 判断介入之前就打上标记；被标记的材料此后必须有独立来源的佐证才可能成为永久锚点。Agent 自己的判断仍然是第二层，负责模式没覆盖到的形状。

## 我们没有在主张什么

这个框架是一个工程问题的来源，不是正确性的证明。

这**不是**人类记忆的模型，也不是从一群彼此并不同意的作者那里提炼出的统一理论。旧接口的 `archive / testimony / interpretation` 标签是**我们协议自己的层级**——它们不是利科的历史认识三阶段，[阅读报告](research/2026-09-19-history-memory-reading.md)记录了这项更正以及每个机制背后的出处。框架标签是过滤器，不是社会模型，也不是访问控制。模式筛查识别的是形状，不是来源认证。而协议只对实际发生的调用做出保证——没有人调用的机制，什么也保护不了。

历史视角真正提供的，是一批存储隐喻从来不会提出的问题：*证人是谁？这是不是同一个证人出现了两次？它支持的是哪一条主张？什么能证伪它？这件事我们当时就知道，还是现在才知道？谁不在记录里，为什么？*

这些问题最后被证明是可以实现的。这就是这个项目押的全部赌注。
